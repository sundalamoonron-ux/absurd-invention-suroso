One-sentence absurd invention pitch for the make.fun bounty
[One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a):
a ridiculous invention that fixes a tiny everyday annoyance, in a single sentence.

## The pitch

> A printer that prints one perfect page and a tiny apology note before jamming, so you forgive it instead of threatening it with the window.

One sentence, 139 characters — inside the 1–220 gate. It won the in-session
pairwise audit 4–0 (undefeated) against 9 other candidates: the laugh comes from
the invention itself (it knows it will jam and pre-apologises), the fix is silly
yet weirdly plausible, and the "threatening it with the window" closer is the
biggest laugh in the field. Full shortlist, pairwise table and runner-up
(C10, passive-aggressive toothpaste, 3–1) in [`candidates.md`](candidates.md).

## Run it

```sh
python3 main.py
```

Writes the pitch to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
Deterministic: the same sentence every run.
